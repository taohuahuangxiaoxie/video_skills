# 视频与舞蹈提示词偏好

- 当用户提供初始视频或舞蹈创意并要求细化提示词时，优先使用已安装的 `prompt-master` 技能生成完整、可复制的细化提示词。
- 工作顺序为：初始创意 → Prompt Master 细化 → 按用户需要转换为 H3 版本。H3 转换使用 `h3-prompt-writing`，保留细化阶段的人物、动作、节奏、镜头和约束，按实际输入模式调整字段、参考标签和时序。
- 用户已给出的目标模型、时长、画幅、语言及参考素材直接沿用；其他导演或平台技能仅在具体细节需要时补充，不替代 Prompt Master 作为创意细化的首选。

## 人物表情与视频处理默认规则（2026-09-29）

- `h3-video-mimic` 为低优先级的旧完整生产流程，不因“模仿视频/舞蹈模仿”等关键词自动启动。仅在用户明确调用或要求继续已采用该技能的工作流时使用；普通视频参考加已准备图片直接按当前任务完成。Prompt Master 仍是提示词细化首选，不自动切换模型、参考模式或创建新对话。
- 生成人物图片、修改人物表情、编写含可见人脸的人物图片/视频/舞蹈提示词时，自动参考 `higgsfield-facs` 的本地自然表情规则；无人物的产品图、场景图和纯文件转码不触发。以自然语言描述嘴角、面颊、眼周协调，身份相似优先，不默认堆AU编号、做表情网格或反复改脸。舞蹈用简短统一表情基调，切镜承接表情；用户明确要求冷淡、严肃等表情时照办，不强行甜笑。
- 视频生成报版权保护/版权审核错误时，调用 `video-copyright-triage`：优先排查参考图片中的角色整套造型与可识别IP，尤其本轮新增/换过的图片，并明确建议更换疑似图片或换成日常原创造型。保留已通过样本作为对比；疑似因素不是平台确认原因。不得仅凭十字架等普通符号认定角色，不默认要求逐图付费测试。
- “处理一下参考视频/预处理参考视频”默认调用 `video-reference-prep`：24fps恒帧率、较低分辨率、无音轨。标准9:16通常576×1024、16:9通常1024×576，其他画幅等比缩入对应包围框；保留完整构图、不放大小图、不变速、不默认裁掉有效首尾。
- “处理生成视频/处理成片”默认调用 `generated-video-finish`：按原始解码帧删除开头1帧、结尾3帧，清理AIGC及平台生成元数据。保留原尺寸、原逐帧时间间隔，音轨存在则同步裁切保留；不套用参考视频的降分辨率、24fps和去音轨默认值。清理元数据不等于证明移除了画面水印或像素级隐写。
- “生成深度视频/做黑白深度参考”默认调用 `temporal-depth-reference`：先将高分辨率/高帧率原片按参考视频规则处理到低分辨率24fps无音轨，再进行真实时序深度估计，最后交付同规格深度视频。不得先对高规格整片推理再缩小，不得普通去色冒充深度，不自动套用成片首1尾3裁切。
- 以上默认均由本次明确偏好授权，后续不重复询问；用户当次指定的帧率、分辨率、音频、裁切或表情覆盖默认。原文件保留，新文件另存，交付前验证帧数、时长、尺寸、时间戳、音轨和完整解码。不自动上传、启动收费成片生成、远程操作或新开对话。

## 换装图片与表情连续性补充（2026-09-29，用户确认）

- 多造型生图把身份与发型分开：固定脸型、五官、肤色和身体比例，按穿搭合理安排披发、半扎发、单马尾、耳后收发或合适帽子，避免复制分缝、刘海分束和碎发。未限定发型时可自行处理，已限定时提醒并给选项；同一造型复现维持对应发型。并排验收整组，不只看单张真实感。
- 舞蹈/换装视频保持情绪连贯，允许笑意自然浮起与收敛、短暂柔和专注且无明显微笑；互动时可短暂露齿，随后放松。切镜承接表情发展，换装不重置；不默认全程微笑、持续露齿或固定嘴部开合。用简短全局描述，不给每个短镜头堆AU或额外表情动作。参考图可在同一亲和基调内稍有差别，身份相似优先。沿用 `higgsfield-facs` 的换装/表情规则；用户指定的情绪与参考表演优先。

## 武侠／仙侠情绪短片（2026-10-02，用户确认）

- 为金庸或其他武侠／仙侠人物构思意难平、情感暗线、平行结局或原创短片时，使用 `wuxia-emotional-storytelling`：以人物选择串联钩子、核心情绪和结尾兑现，交代关键因果。单纯讨论创意和剧本不自动进入提示词或素材生成；到提示词细化阶段再结合 Prompt Master，沿用用户指定模型。
- 为这类短片设计或审核参考图、镜头、表演及视频提示词时，使用 `wuxia-visual-direction`：保持唯美电影质感与角色连续性，按人物关系安排机位和反应镜头，控制自然微表情，并提前设计素材剪接点。与 FACS 自然表情规则配合，明确的角色情绪优先，不强行微笑或苦相。
- 武侠／仙侠短片的生成素材严格禁止配乐，允许指定对白、环境声和同步非音乐特效音，配乐留给用户后期统一处理；这不是对所有题材或最终成片的禁乐要求。两份技能不固定模型、画幅、时长、倍速或特效模板，不把单次传播数据当作成功公式；用户当前明确要求优先。
